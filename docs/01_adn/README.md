# 01_adn — ce qui définit Lédjé

**Rôle** : l'identité du projet — vision, positionnement, combats, cible, marque, conformité,
identité visuelle. C'est la zone qui bouge le moins et qui contraint tout le reste : avant
d'écrire un texte, de compiler un prompt ou d'ouvrir un canal, c'est ici qu'on vérifie.

## Règle de lecture — à lire avant d'utiliser ces fiches

Ces fiches décrivent des objets **différents**, souvent confondus. La plupart des erreurs de
production viennent d'une confusion entre deux d'entre eux. Ne jamais confondre :

- **la cible** avec **le territoire** — qui on adresse n'est pas ce qu'on montre ;
- **le territoire** avec **la personnalité** — l'univers créatif n'est pas le caractère de la marque ;
- **la personnalité** avec **le ton** — ce que la marque est n'est pas la façon dont elle parle ;
- **la personnalité de la marque** avec **l'émotion générée chez le consommateur** — Lédjé peut
  s'exprimer avec énergie tout en laissant une sensation d'apaisement ;
- **la vision** avec **la proposition de valeur** — l'une guide la marque, l'autre parle au client ;
- **les hypothèses consommateur** avec **des vérités** — une hypothèse non testée reste une hypothèse,
  même si elle est bien écrite ;
- **l'origine religieuse du produit** avec **une obligation de communication religieuse** — le produit
  vient d'une tradition, la marque n'a pas à prêcher.

Le fil qui relie tout, et qu'il faut pouvoir refaire à tout moment :

> **un produit très simple → une expérience agréable → une évidence → une sérénité → une cohérence désirable.**
