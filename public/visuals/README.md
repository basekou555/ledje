# Visuels de la landing page Lédjé

Dépose ici tes images (générées sur ChatGPT Image / Gemini / Higgsfield), avec ces noms
EXACTS. Le site les affiche automatiquement. Tant qu'un fichier manque, la zone reste un
bloc coloré neutre (pas d'image cassée).

Format conseillé : JPG optimisé (< 300 Ko chacune), assez large (~1400 px).

> ⚠️ **Ce dossier est une DESTINATION, pas une bibliothèque.** On n'y met que les images
> **élues**, sous les noms fixes que le code attend. L'historique des générations, les
> verdicts et ce qu'on en a appris vivent dans [`docs/visual/ledje-asset-log.md`](../../docs/visual/ledje-asset-log.md) ;
> les plans et leurs recettes dans [`docs/visual/ledje-shot-book.md`](../../docs/visual/ledje-shot-book.md).

## Deux corrections de vocabulaire et de palette (2026-09-11)

- **« perle » était employé trois fois** : c'est un **interdit de lexique**
  (`docs/01_adn/identite-verbale.md` §4.3 — *portion · monodose · perle · pastille*).
  Le terme verrouillé est **cristal de miel**. Corrigé.
- **« fond émeraude conseillé » est retiré** : la palette est rouverte depuis le 2026-07-28
  — seul l'émeraude tient comme couleur de marque, mais **rien n'impose un fond émeraude**,
  et l'étiquette réelle est crème. Le décor validé à la production est `DEC-05`
  (travertin + enduit, lumière rasante) — cf. `ledje-prompt-library.md`.

⚠️ Les fichiers présents datent d'août et **précèdent** l'étiquette v1.2 comme le premier lot
de générations validées. Ils sont à remplacer.
